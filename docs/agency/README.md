# Agency-internal documents

**These are yours, not the client's. Delete `docs/agency/` from every client
fork before handing the repository over.**

A prospect finding your pricing sheet and margin notes in their own repo is an
avoidable, expensive conversation. `npm run check:content` warns when this
directory is still present.

| File | What it's for |
| --- | --- |
| [PRICING.md](PRICING.md) | How to structure and calibrate what you charge |
| [PROPOSAL.md](PROPOSAL.md) | Fill-in proposal to send a prospect |
| [CONTENT-INTERVIEW.md](CONTENT-INTERVIEW.md) | The call that produces the site's copy |

The client-facing documents are [CLIENT-INTAKE.md](../CLIENT-INTAKE.md) and the
[README](../../README.md). Those stay.
